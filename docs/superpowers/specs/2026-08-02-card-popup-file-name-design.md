# 카드 툴팁 실제 파일명 표시 설계

## 목표

영상 카드 툴팁의 표시 제목 바로 아래에 확장자를 포함한 실제 파일명을 한 줄로 표시한다.

## 범위

- `VideoItemViewModel`은 기존 `Path`에서 마지막 파일명 구성 요소를 계산해 제공한다.
- 카드 툴팁은 표시 제목과 상세 정보 사이에 실제 파일명을 배치한다.
- 전체 경로, 새 설정, 새 변환기, 팝업 크기 변경은 추가하지 않는다.

## 설계

`VideoItemViewModel`에 `System.IO.Path.GetFileName(Path)`를 반환하는 읽기 전용 `FileName` 속성을 추가한다. 별도 변환기나 캐시는 만들지 않는다.

툴팁의 `DisplayTitle` 바로 아래에 `FileName`을 바인딩한 `TextBlock`을 둔다. 기존 보조 정보와 어울리도록 글자 크기는 10px, 색상은 `MutedBrush`를 사용한다. 파일명은 한 줄로 유지하고 공간을 넘으면 문자 단위 말줄임을 적용한다. 기존 제목의 아래 여백을 파일명 위·아래 여백으로 나눠 전체 간격과 팝업 너비를 유지한다.

## 데이터 흐름

`VideoItemViewModel.Path` → `FileName` → 카드 팝업 `TextBlock.Text`

경로는 라이브러리 스캔에서 제공되는 기존 필수 값이므로 별도 빈 값 대체 문구나 오류 처리는 추가하지 않는다.

## 검증

- 경로에서 확장자를 포함한 마지막 파일명이 계산되는지 단위 테스트한다.
- 실제 카드 팝업 바인딩이 계산된 파일명을 표시하는지 WPF 테스트로 확인한다.
- 관련 카드 팝업 테스트와 전체 테스트를 실행한다.
- Release 빌드가 경고와 오류 없이 완료되는지 확인한다.
