# DABOM 검색어 초기화 UX delta 스펙

## 문서 성격

- 기존 DABOM Windows 데스크톱 앱의 메인 라이브러리 검색창과 메타데이터 편집 검색란에 같은 검색어 초기화 동작을 추가하는 UI delta 스펙이다.
- 핵심 목적은 입력한 검색어를 마우스 또는 키보드로 즉시 지우고, 두 검색 화면에서 일관된 동작을 제공하는 것이다.
- 검색과 메타데이터 조회 규칙, 검색 결과 적용 방식 및 저장 동작은 변경하지 않는다.

## 범위

- 메인 화면의 `제목, 감독, 배우 이름으로 검색` 검색창과 메타데이터 편집 창의 온라인 검색란을 대상으로 한다.
- 두 검색란 우측 끝에 검색어가 있을 때만 원형 `×` 초기화 버튼을 표시한다.
- 메인 검색창에서는 검색어가 없을 때 기존 `Ctrl K` 안내 배지를 표시하고, 검색어가 있으면 같은 우측 영역에 초기화 버튼을 표시한다.
- 메타데이터 검색란의 `온라인 검색` 버튼은 기존 위치와 동작을 유지하며, 초기화 버튼은 검색 입력 영역 내부 우측에 표시한다.
- 공용 검색 컨트롤, 새 ViewModel 명령, 새 의존성 및 애니메이션은 추가하지 않는다.

## 사용자 흐름과 동작

1. 검색어가 비어 있으면 초기화 버튼은 보이지 않는다.
2. 사용자가 검색어를 입력하면 검색란 우측 끝에 초기화 버튼이 나타난다.
3. 초기화 버튼을 클릭하면 해당 검색어가 빈 문자열로 바뀌고 검색란이 다시 키보드 포커스를 받는다.
4. 검색란에 키보드 포커스가 있고 검색어가 비어 있지 않을 때 `Esc`를 누르면 초기화 버튼 클릭과 동일하게 검색어를 지우고 포커스를 유지한다.
5. 검색란 밖에 포커스가 있거나 검색어가 이미 비어 있을 때는 `Esc`를 검색어 초기화가 소비하지 않으며, 각 창의 기존 `Esc` 동작을 유지한다.
6. 메타데이터 검색어를 버튼 또는 `Esc`로 초기화하면 열려 있는 검색 결과 팝업도 닫는다. 이 동작은 새 온라인 검색을 시작하지 않는다.
7. 메타데이터 검색 결과로 적용했거나 사용자가 직접 편집한 제목, 원제, 공개일, 감독, 배우, 줄거리, 포스터 및 회차 값은 검색어 초기화로 변경하지 않는다.

## UI와 접근성

- 초기화 버튼은 검색란 안쪽 우측에 떠 있는 원형 버튼으로 표현하며, 입력 텍스트와 겹치지 않도록 검색란의 우측 여백을 확보한다.
- 버튼은 현재 테마의 색상과 포커스·호버 표현을 재사용하고, 검색란의 높이와 시각적 위계를 바꾸지 않는다.
- 버튼의 접근성 이름과 도구 설명은 `검색어 지우기`로 제공한다.
- 버튼은 Tab으로 접근할 수 있으며 키보드로 실행한 뒤 검색란으로 포커스를 돌려 연속 입력이 가능해야 한다.
- `Ctrl+K`로 메인 검색창에 포커스를 주는 기존 동작은 유지한다.

## 상태와 경계 조건

- 메인 검색어 초기화는 기존 `SearchText` 바인딩을 통해 즉시 전체 영상 목록을 다시 표시한다. 기존 필터링 과정에서 해제된 영상 선택은 자동 복원하지 않는다.
- 메타데이터 검색어 초기화는 `SearchText`와 결과 팝업의 열림 상태만 변경한다. 기존 후보 데이터, 편집값, 오류 메시지 및 저장 상태는 변경하지 않는다.
- 메타데이터 조회 또는 저장 중에는 기존 화면 비활성화 정책을 그대로 따른다.
- 초기화 자체는 파일, 설정 또는 메타데이터를 저장하지 않으므로 실패 메시지나 복구 흐름을 새로 추가하지 않는다.

## 구현 경계

- 각 창의 기존 XAML에 초기화 버튼과 표시 조건을 추가한다.
- 각 창의 기존 코드 비하인드에서 버튼 클릭과 검색란 포커스 상태의 `Esc`를 처리한다.
- 두 창을 위한 공용 컨트롤이나 공용 명령은 만들지 않는다. 현재 두 위치의 작은 UI 차이를 유지하는 편이 새 추상화보다 단순하다.
- 기존 검색 필터, 온라인 조회, 결과 선택 및 저장 코드는 변경하지 않는다.

## 검증

- GUI 창을 띄우지 않는 기존 테스트 방식으로 두 XAML에 초기화 버튼, 접근성 이름, 클릭 연결 및 검색어 기반 표시 조건이 존재하는지 검증한다.
- 기존 코드 비하인드 계약 테스트를 확장해 검색란의 `Esc` 초기화와 메타데이터 결과 팝업 닫기가 연결되어 있는지 검증한다.
- 기존 메인 검색 필터 테스트와 메타데이터 검색 테스트를 실행해 검색 및 저장 흐름에 회귀가 없는지 확인한다.

## 수용 기준

1. 두 검색란 모두 검색어가 있을 때만 우측 끝에 `×` 초기화 버튼을 표시한다.
2. 초기화 버튼을 클릭하면 검색어가 즉시 비워지고 검색란 포커스가 유지된다.
3. 검색란에 포커스가 있을 때 `Esc`를 누르면 버튼 클릭과 같은 초기화가 수행된다.
4. 검색란 밖의 `Esc`와 검색어가 이미 비어 있을 때의 `Esc`는 기존 동작을 유지한다.
5. 메타데이터 검색 초기화 시 결과 팝업이 닫히고 편집값은 보존된다.
6. 메인 검색창의 `Ctrl+K` 포커스, 메타데이터의 온라인 검색, 결과 선택 및 저장 동작은 기존과 동일하게 동작한다.
7. 초기화 버튼은 `검색어 지우기`라는 접근성 이름을 제공하고 키보드로 조작할 수 있다.

## 제외 범위

- 검색 기록, 최근 검색어, 실행 취소, 자동 완성 및 별도 단축키는 추가하지 않는다.
- 검색 결과 수 애니메이션이나 초기화 완료 알림은 추가하지 않는다.
- 검색창 외 다른 입력란에는 같은 초기화 버튼을 확장하지 않는다.
- 미결정 항목과 후속 검토 항목은 없다.
